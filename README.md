# MDVLCraft

A Forge **1.20.1** (Forge **47.4.10**) modpack built around Epic Fight combat, class and archetype skill trees with an ability wheel, Origins, Iron's Spells and Cursed Fate.

| File | What it is |
|------|------------|
| [`MDVLCraft-1.9.31-client.mrpack`](MDVLCraft-1.9.31-client.mrpack) | Client Modrinth pack (Modrinth App, Prism Launcher). Set 8 GB and the JVM line from [`MDVLCraft-1.9.31-Client-Java-Arguments.txt`](MDVLCraft-1.9.31-Client-Java-Arguments.txt) in the launcher |
| [`MDVLCraft-1.9.31-server.mrpack`](MDVLCraft-1.9.31-server.mrpack) | Dedicated server Modrinth pack (matches the client pack). Use the JVM arguments in [`MDVLCraft-1.9.31-Server-user_jvm_args.txt`](MDVLCraft-1.9.31-Server-user_jvm_args.txt) as the server's `user_jvm_args.txt` |
| [`MDVLCraft-1.9.31-Skill-Trees.pdf`](MDVLCraft-1.9.31-Skill-Trees.pdf) | Every archetype's stats, abilities, Epic Fight skills and bonuses, and every Origins race, Martial class and Job with their powers |

## Origin selection

On first join every player picks three origins, in this order (the Orb of Origin resets all three):

1. **Race** (21): Human, Feline, Merling, Arachnae, Dwarf, Wood Elf, Goblin, Siren, Ogre, Land Shark, Kirin, Raptus, Rat, Shadow, Sporeling, Stoneborn, Infernal, Dryad, Orc, Kobold, Revenant.
2. **Job**, the everyday profession (17): Blacksmith, Cleric, Cook, Farmer, Merchant, Rancher, Miner, Lumberjack, Explorer, Alchemist, Sailor, Fisher, Bard, Herbalist, Beekeeper, Gravedigger, Nitwit.
3. **Martial**, the combat profession (18): Warrior, Archer, Rogue, Beastmaster, Cavalry, Duelist, Guardian, Skirmisher, Crossbowman, Spearman, Monster Hunter, Bounty Hunter, Battle Mage, Sentinel, Paladin, Corsair, Zealot, Nitwit.

The status page (M menu → Status) shows Race, Martial and Job. Every power is listed in the skill-tree PDF.

**Java:** 17. **RAM:** 8 GB client.
