# Skill tree totals

Every bonus in each archetype tree added up, read from the tree data in `src/main/resources/data/mdvlcraft/puffish_skills`. These are the totals for a **whole** tree. A player gets 41 points per archetype (1 to start, 1 per level up to level 40) and every tree costs far more than that, so one character only ever gets part of a tree. Players pick 2 archetypes.

"Slower hunger" is Pufferfish's Stamina attribute (food drains more slowly). "%" values add to the base; flat values are points (Max Health in half-hearts).
