# Orca's domains (JujutsuCraft ver51), decompiled for reference

From Orca's JujutsuCraft (used with his permission; credit in `binder/README.md`). Research only: nothing here is
built into the binder. `MDVLCraft-Orca-Domains-Report.pdf` explains the system, lists every domain, assigns one per
archetype and estimates the work. `src/` holds the decompiled (Vineflower) domain classes: the domain core
(`DomainExpansion*`, `DomainActive`, `GetDomainBlock`, `BreakDomain`, Simple Domain and Domain Amplification), each
domain's effect procedure, the domain blocks, the prop entities and their models, and the shared attack procedures the
domains call (`RangeAttack`, `LogicAttack`, `LogicAttackDomain`, `ChangeCurseEnergy`). JujutsuCraft must not become a
pack dependency (Orca's request).
